五、关键发现

  • 结构占比：L0 中 Toy Experience（玩具/体验）占 55.4%，其次 Game 37.3%、Tool 6.8%；93% 的 id 已用上 v2 打标。
  • 曝光：曝光VV 中位 55.7K，而均值 174.5K、最高 2.28M —— 长尾极强，评估用中位数；各 L0 里 Game 曝光中位最高（69.2K）。
  • 互动：点赞率整体中位 1.44%；Ambient & Watch（氛围与观看）点赞率中位最高 3.38%（n=124）。氛围观看 / 工具类互动率普遍高于强游戏玩法。
  • 发布节奏：集中在 2026-05 与 06，两月合计 73%；样本主要来自近三个月。
  • 两表关系：共有 2349 / 各独有 651；共有 id 标签与指标一致，对比只需看成员差异。
